# Project instructions

Read `.versat/project.yaml`, `.versat/standards.lock`, active changes under `specs/changes/` and applicable repository documentation before working.

Follow the resolved Versat Standards and Versat SDD. Run the project's documented validation entry point before completion. Do not bypass required checks or infer authorization for remote and high-impact actions.

When adding or running Skills, custom agents or operational workflows, apply the artifact contract from the resolved Standards. Consult the project's architecture for capability bindings, supported executor and readiness; the presence of a workflow document alone is not proof that its dependencies can execute.
