# Revisar a arquitetura

[English](architecture-review.md) | [Português](architecture-review.pt.md) | [Español](architecture-review.es.md)

Use esta revisão quando limites do sistema, riscos arquiteturais ou um ADR estiverem no escopo. Forneça Proposal/Requirements, Design, arquitetura atual, ADRs relacionados e contexto aplicável do projeto.

## Experimente

Pedido ilustrativo; substitua o ID ou forneça os dados reais do projeto:

```text
Use $architecture-review para revisar este design proposto conforme a arquitetura atual e os Standards resolvidos. Comece pelos riscos relevantes, evidências e decisões de ADR necessárias. Não implemente mudanças.
```

## Resultado esperado

Espere achados com evidências sobre responsabilidade, limites de confiança/dados, falhas e recuperação, operações, compatibilidade e migração. Separe correções necessárias de melhorias opcionais. Decisões relevantes devem estar em ADRs revisáveis; a existência de um arquivo não comprova a qualidade da decisão.

## Recuperação e limites

Arquitetura ausente ou especificações conflitantes devem ser reportadas antes de confiar no design. Mantenha distintas as responsabilidades de políticas, capacidades, ciclo e aplicação mecânica. A revisão não autoriza implementação nem publicação.
