# Revisar la arquitectura

[English](architecture-review.md) | [Português](architecture-review.pt.md) | [Español](architecture-review.es.md)

Usa esta revisión cuando los límites del sistema, los riesgos arquitectónicos o un ADR estén en alcance. Proporciona Proposal/Requirements, Design, arquitectura actual, ADRs relacionados y contexto aplicable del proyecto.

## Pruébalo

Solicitud ilustrativa; reemplaza el ID o proporciona los datos reales del proyecto:

```text
Usa $architecture-review para revisar este diseño propuesto según la arquitectura actual y los Standards resueltos. Comienza por riesgos relevantes, evidencia y decisiones de ADR necesarias. No implementes cambios.
```

## Resultado esperado

Espera hallazgos con evidencia sobre responsabilidad, límites de confianza/datos, fallas y recuperación, operaciones, compatibilidad y migración. Separa correcciones necesarias de mejoras opcionales. Las decisiones relevantes deben estar en ADR revisables; la existencia de un archivo no demuestra la calidad de la decisión.

## Recuperación y límites

La arquitectura faltante o las especificaciones contradictorias deben informarse antes de confiar en el diseño. Mantén separadas las responsabilidades de políticas, capacidades, ciclo y aplicación mecánica. La revisión no autoriza implementación ni publicación.
