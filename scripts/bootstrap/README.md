# Bootstrap scripts

Reserved for deterministic project composition and local initialization. Scripts must accept an explicit destination, refuse destructive overwrite by default and record the applied Harness version and template modules.

No executable composer is supplied yet. Follow the [composition and migration guide](../../project-templates/README.md), including hidden consumer directories and shared base files. Authoring templates and examples are not profile modules. Verify the target project's artifact and executor contracts separately from the Harness Plugin package.
